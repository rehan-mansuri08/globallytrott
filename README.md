# GlobeTrotter Planner

"I want to build a full-stack travel planning application called 'GlobeTrotter'. The design must strictly follow a sleek, modern developer portfolio aesthetic—deep dark mode, minimalist typography, and translucent glassmorphism panels.  First, set up the database and landing page:Supabase Setup: Generate and execute the SQL schema for Trips, Stops, and Activities. Ensure Row Level Security (RLS) is enabled.  3D Background: Install @react-three/fiber and @react-three/drei. Create a full-screen canvas background with a slowly rotating 3D curved plane displaying a seamless, royalty-free MP4 video of nature.Auth Shell: Build a centered, glassmorphism Login/Signup card overlaying the 3D background. Connect it to Supabase Auth.

"Now, build the protected Dashboard/Home Screen. Ensure the 3D video background persists but is slightly dimmed.

Create a 'bento-grid' layout using Tailwind CSS and shadcn/ui components. The grid should include:

A personalized welcome message.

A card listing upcoming trips.

A prominent 'Plan New Trip' call-to-action button.

A card showing budget highlights. Include a sleek top navigation bar to manage the user profile and settings."
